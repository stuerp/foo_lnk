
# foo_lnk

[foo_lnk](https://github.com/stuerp/foo_lnk/releases) is a [foobar2000](https://www.foobar2000.org/) component that adds shell link support to foobar2000.

It is based on [foo_lnk](https://github.com/stengerh/foo_lnk) by [Holger Stenger](https://github.com/stengerh).

## Requirements

* Tested on Microsoft Windows 10 and later.
* [foobar2000](https://www.foobar2000.org/download) v1.6.16 or later (32 or 64-bit). ![foobar2000](https://www.foobar2000.org/button-small.png)

## Getting started

* Double-click `foo_lnk.fbk2-component`.

or

* Import `foo_lnk.fbk2-component` into foobar2000 using "File / Preferences / Components / Install...".

## Developing

### Building

Open `foo_lnk.sln` with Visual Studio and build the solution.

### Packaging

To create the component first build the x86 configuration and next the x64 configuration.
